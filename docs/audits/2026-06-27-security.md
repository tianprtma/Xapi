# Security Audit & Hardening — Xapi
Date: 2026-06-27

## Changes Applied

### Phase 1 — Token Leak Prevention (CRITICAL)
**Previously**: Every `?raw=1` response returned `"cookies": {..}` (full X.com cookie jar) + `"tokens": {auth_token, ct0, bearer}`. The `/login` endpoint also leaked cookies.

**Fix**:
- `app/responses.py` — added `_strip_sensitive()` function, called in `wrap()` for all raw-mode responses
- `app/clients.py` — removed `"cookies"` and `"tokens"` from ALL 10 inline error dicts + `_invalid_token_response()` helper
- `playwright_search.py` — removed `"cookies"` from `_action_via_browser_impl`, `_fetch_via_browser_impl`, `_search_via_browser_impl` return dicts
- `app/routers/infra.py` — login endpoint now strips full cookie jar from response, keeps only user profile + minimal tokens

### Phase 2 — Input Validation
**Previously**: 19 bare `PathParam(...)` without pattern (unvalidated string params). Query sanitizer silently bypassed on UTF-8 decode failure. No Content-Type enforcement.

**Fix**:
- Added `pattern=r"^\d+$"` to all bare PathParam in `routers/dm.py` (12), `routers/media.py` (2), `routers/spaces.py` (3), `routers/users.py` (2), `routers/birdwatch.py` (1)
- Added `ContentTypeValidationMiddleware` in `app/security.py` — rejects non-JSON POST/PUT/PATCH on `/2/` endpoints
- Fixed `app/sanitize.py:133` — replaced `except Exception: pass` with `except (UnicodeDecodeError, ValueError)` returning proper 400 JSON response via ASGI

### Phase 3 — Rate Limiting
- `app/security.py` — per-IP fallback keys now prefixed with `"ip:"` when no valid auth_token
- Minimum `retry_after` floor raised to `5s` (was 1s) to prevent tight retry loops

### Phase 4 — Error Handling
- `main.py` — added `@app.exception_handler(Exception)` for global 500 — returns consistent JSON error, logs full traceback server-side
- `main.py` — removed `Server` header from uvicorn response

### Phase 5 — Audit Logging
- `app/routers/infra.py` — admin config changes (PIN set, bridge start) now logged via `xapi.admin` logger

### Phase 6 — Playwright + XChat
- `playwright_search.py` — WEB_BEARER now passed as JS evaluate parameter instead of hardcoded in page script
- `app/routers/infra.py` — XChat bridge keys now show only user_id (auth_token prefix stripped)
- `app/xchat/bridge.py` — profile_dir uses `sha256(auth_token)[:16]` instead of plaintext `auth_token[:32]`
- `tid_provider.py` — added timeouts (connect=5s, read=10s) to `requests.Session()`
